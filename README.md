A single line of text: the excuse a gamer texts the boss to skip work on GTA 6 launch week, judged head to head on how believable it sounds to a tired manager.

Our line: "My landlord's replacing the front door today and I'm locked in until the locksmith finishes at noon." The program writes that one line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
